Premier lancement

L’application est gratuite et n’est pas enregistrée auprès de Microsoft ni d’Apple (cela coûte cher chaque année). Votre ordinateur demande donc une confirmation, une seule fois.

Windows : « Windows a protégé votre ordinateur »
  1. Ouvrez le fichier téléchargé Plateforme-educative-Windows.exe.
  2. Si un écran bleu apparaît, cliquez sur Informations complémentaires, puis sur Exécuter quand même.
  3. L’application s’installe et s’ouvre. Elle est ensuite dans le menu Démarrer et sur le Bureau.
Mac : « impossible de vérifier le développeur »
  1. Ouvrez le fichier .dmg téléchargé et glissez l’icône dans le dossier Applications.
  2. Ouvrez l’application depuis le dossier Applications. Si le Mac refuse, cliquez sur OK.
  3. Allez dans Réglages Système → Confidentialité et sécurité, descendez en bas de la page et cliquez sur Ouvrir quand même, puis confirmez.

Sur les Mac plus anciens : clic droit (ou Ctrl + clic) sur l’application → Ouvrir → Ouvrir.

Linux
  1. AppImage : clic droit sur le fichier → Propriétés → cocher « Autoriser l’exécution », ou dans un terminal chmod +x Plateforme-educative-Linux.AppImage, puis double-clic.
  2. Paquet .deb : double-clic pour l’installer, ou sudo apt install ./Plateforme-educative-Linux.deb.
Téléphone et tablette : ajouter à l’écran d’accueil
  1. Android : ouvrez le site dans Chrome, touchez le menu ⋮ puis Ajouter à l’écran d’accueil (ou Installer l’application).
  2. iPhone et iPad : ouvrez le site dans Safari, touchez Partager puis Sur l’écran d’accueil.
